# JavaScript Fundamentals – Arrays, Recursion, Objects & Problem Solving

**Author:** Mohammad Aminul Islam  
**Collection:** First Repository Insight  
**Language:** JavaScript  
**Resource Type:** Educational JavaScript Notes & Code Examples  
**Availability:** Free Educational Resource

## Introduction

This resource combines two JavaScript learning files focused on programming fundamentals, array manipulation, recursion, objects, loops, and practical problem-solving techniques.

Through commented code examples and terminal output demonstrations, learners explore how to work with JavaScript data types, search and modify arrays, remove duplicate values, perform recursive calculations, and search product information using functions.

## Topics Covered

### 1. JavaScript Data Types and Fundamentals
- Understanding JavaScript variables and data types
- Using `typeof` to identify data types
- Working with strings, numbers, and Boolean values
- Understanding arrays, objects, and functions
- Checking arrays with `Array.isArray()`

### 2. Array Methods
- Checking array elements using `includes()`
- Combining arrays using `concat()`
- Extracting elements using `slice()`
- Removing elements using `splice()`
- Understanding the differences between array operations

### 3. Removing Duplicate Items from an Array
- Creating a function to remove duplicate values
- Iterating through array elements
- Checking existing values with `includes()`
- Building a new array containing unique elements

### 4. Loops and Conditional Logic
- Generating numbers from 1 to 50 using a `for` loop
- Checking divisibility using the remainder operator (`%`)
- Applying conditional statements
- Practicing the `foo`, `bar`, and `foobar` exercise
- Replacing numbers with text based on divisibility rules

### 5. Mathematical Calculations and Wood Requirements
- Understanding fixed and variable quantities
- Using multiplication to calculate material requirements
- Working with chair, table, and bed wood requirements
- Practicing function-based calculation logic

### 6. Understanding Recursion
- Understanding recursion as a function calling itself
- Calculating the sum of numbers using loops
- Comparing iterative and recursive approaches
- Exploring recursive function calls
- Understanding base cases and recursive calls

### 7. Factorial Recursion
- Exploring factorial calculations
- Understanding multiplication through recursive calls
- Practicing recursive function structure

### 8. Advanced JavaScript Objects
- Creating objects with multiple properties
- Working with strings, numbers, and Boolean properties
- Storing arrays inside objects
- Creating nested objects
- Accessing object properties
- Exploring the `arguments` object inside functions

### 9. Array Iteration and Product Searching
- Iterating through arrays using traditional `for` loops
- Using `for...of` to access array values
- Working with arrays of product objects
- Searching product names using `includes()`
- Creating a `matchedProducts()` function
- Collecting matching products into a new array

## Learning Approach

The files use commented JavaScript examples, sample inputs, and expected terminal outputs to explain programming concepts progressively.

The learning exercises move from basic data types and array methods to recursion, object handling, conditional logic, and product-search functions. This approach helps learners understand how JavaScript concepts work together in practical programming scenarios.
